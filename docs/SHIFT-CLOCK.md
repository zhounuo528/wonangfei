# 倒计时与上班打卡提醒

未开始时，首页和迷你窗显示「距离上班」，使用当天或最近一次有效安排的计划上班时间；同日已下班后跳过已完成日期。当天计划上班时间已过但还没开始，即使超过计划下班时间，仍显示「上班时间已到」和零倒计时，等待用户开始，不自动跳到明天、不自动打卡。

开始后切换「距离下班」，保留按当天计划时间补算的收入规则；提前点击仍等待计薪窗口。进行中的计划外加班和休息日加班继续显示红色「已加班」，无额外自动收入。下班后立即转为下一次上班倒计时；原加班结算留在总结、日历和报表，不继续增长。返工仍创建独立时段、恢复适用的下班或加班计时。

下一次安排尊重单日上班、休息日加班、请假、调休、休息、996、全年无休和大小周基准。没有循环工作日且没有未来单日上班安排时，显示「暂无上班安排」和空值，不编造时间。循环搜索覆盖完整 14 天考勤周期及有限日期覆盖，单独的远期安排也可以找到。只读取本地设置与记录，不创建记录或重算工资、成本和目标。

本版计划上下班仍限同日，设置校验拒绝结束早于开始；本轮不新增跨午夜夜班排班。已经开始后跨午夜不自动结束，继续归属原班次并计加班；显式下班后再显示当前日期或未来下一班的上班时间。

「开启上班打卡提醒」是独立开关，默认关闭。主动开启后，从开启时间之后的下一次计划开始起提醒；上班时间已经过去才开启，不立即追弹当天提醒。必须当天在计划开始到结束之间、没有实际上班记录、没有其他进行中的班次才提醒；提前点击、已下班、请假、调休、休息或未来日期不触发。明确安排的休息日加班也按自己的计划开始时间提醒。

文案为「该打卡了，班可不能白上。」，确认按钮只关闭弹窗，不开始上班。沿用现有下班提醒的应用内弹窗，不调用系统通知 API，不请求或改变系统通知权限。窗口隐藏、网页后台或休眠时不显示；当天排班内恢复可补提醒一次，超过计划结束不补弹。应用退出、网页关闭或系统未运行时不能提醒。

每个本地日期最多一次，先保存送达标记再显示。存储失败不显示且不消耗送达，恢复后可重试；重启、重复开启或当天修改排班不清空标记。其他对话框打开时等待，显示前再次核对未打卡、当前安排和开关，避免过期弹窗。原下班提醒开关、文案和记录独立保留。

新增可选字段 `clockInReminder`，包含 enabled、enabledAt、按日期的 delivered。旧记录没有此字段仍可读取，单纯打开设置不补写；用户明确开启才创建。该字段不影响财务计算，不单独升级内容格式。已有格式 4 继续保持，0.4.4／桌面 0.3.4 对格式 4 的回退限制仍适用；上线前保留备份，不清站点数据。实际数据全部保存在原本机或浏览器。
