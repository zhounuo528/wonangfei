# 0.3.4 验收记录（2026-11-04）

所有测试使用隔离虚拟数据，未读取真实财务档案、安装或清理用户应用。

桌面单元测试 162 项通过；UTC、Asia/Shanghai、America/Los_Angeles 三时区通过。网页单元测试 164 项通过，静态构建 29 个公共资源。

最终 ARM 和 Intel DMG 均校验磁盘镜像、只读挂载、复制到自己的临时目录，严格 codesign 校验后通过 LaunchServices open 启动。ARM 本机 macOS 27.2 / Electron 45.2.1 运行 48 组检查（新增工资／重分／周报 13、工资和存储回归 15、日历回归 20）；x64 在同一机器 Rosetta 下运行同样 48 组，translated=true。两个架构各通过实际旧 0.3.3 模型生成的档案升级、显式修复零工资补录、保留手动例外／加班费／已完成目标并完整重启。测试模型源码逐字节匹配旧版 app.asar。

网页使用 localhost HTTP、无 preload／Node／桌面 bridge 的独立 Chromium 窗口和真实 IndexedDB：新增流程 13 组、保留工资与存储 17 组、日历 19 组通过。包含真实首次填写工资、补记 1–3 日、部分工时、取消与撤销日期调薪、手动旧薪修复、未来普通补班整月重分、休息日加班费、周月均薪、备份导入导出、并发冲突、配额失败及损坏保护。390px 窄屏截图无页面横向溢出；已查看实际截图，不是效果图。

Windows 安装器 7zip 完整性通过，解包的程序是 PE x64，无 Authenticode；安装器是 x86 NSIS 引导、包含 x64 载荷。仅当前用户安装、卸载明确文件清单且保留 AppData。三架构 app.asar 完全相同，SHA-256 为 149a05d18345d0a3d02d72605063217cfc689c936e33ac7c5b82f956d1572871，51 个产品文件与当前 src/desktop 逐文件相同，无运行档案、测试、缓存或凭据。

最终 ARM 包也通过实际 0.3.0 模型生成的档案升级和完整重启，薪资、固定费用、摸鱼、加班费及已完成目标保留，旧演示归档逐字节不变。0.3.3 旧模型及旧存储读取格式 3 时拒读并锁定，无法覆盖原文件，字节保持不变。回退仍需升级前备份，不能只替换应用或网页。旧首笔 0→工资须由用户判断是否首次填写，不自动重写手动历史；目标创建前的补记不进入目标池。
