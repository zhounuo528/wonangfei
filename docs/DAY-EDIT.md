# 日期详情统一修改与记录格式 4

日期详情保留一个「修改」入口，直接显示已有上下班时段、多笔当日临时花销、当日固定负担选择。多次返工全部展开，不要求先选第几段；跨午夜仍归原班次日期。需要改变请假／调休等类型时，从编辑内的「调整当天安排」进入原安排表单。首页时间修正保持时间入口，不混入日费用表单。

临时花销可增加、改名、改金额、删除，带 ID 的项目只能来自当前日期；预览不落账，保存后的记录保留 ID。原整月分摊在此只显示，仍到费用管理调整，不能把整月金额当作当日临时花销重复记录。未改动的旧金额和原时间精度保留；显示两位小数。

原已计入的固定负担默认保留；没有原分摊时默认不补扣。只有用户主动勾选，才展示项目、金额和来源并保存当日快照。优先沿用已保存快照或当日原分摊；历史没有可用分摊时，按当前有效固定项目的月均金额与各项目留存考勤的该月计划工作日折算，界面标注「按当前固定项目补计此日」。当月零工作日不能编造分摊。取消勾选只排除此日，项目定义及其他日期不变；保存的当日快照不随以后项目变化悄悄重算。

保存前显示收入、临时费用、固定负担、净额、工时、加班费和目标余池变化。单纯修改时间或费用不会创建新排班／补班或重分其他日期工资。保留已记加班费、摸鱼、原时段；影响有效工时少于摸鱼时长时拒绝保存。关闭或取消不保存，重复保存有状态与写入守卫。

修改前后原日记录和当日费用留在同一审计条目。撤销前比较此日最新状态；其后有同日新记录时阻止整笔覆盖，保护后续记录。可恢复该日原时间、费用和固定选择，并保留其他日期新增记录。新费用会影响对应日／月统计和创建日以后的目标来源；目标创建前不追溯，已完成目标结算不撤销或重复，即使余池随后变负。

费用快照和费用审计使用内容格式 4；只读旧档案或仅查看版本不会因此升级。新读者支持格式 1/2/3/4，IndexedDB 名称及数据库 schema 1 不变。桌面 0.3.4、网页 0.4.4 不认识格式 4，旧读者拒读，不能靠回滚静态文件恢复账本。升级前导出备份；回退先保留升级后的记录，再配合升级前备份或兼容的向前修复，不清站点数据或强改格式号。

单元与真实界面已覆盖补录／已有日、多项费用、取消、撤销、跨午夜、目标池、原加班费、其他日隔离、隐藏金额及手机视口。仅使用虚拟档案，未使用用户截图中的个人金额或读取真实档案。
