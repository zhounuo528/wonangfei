# Calendar and time correction - web 0.4.3

Business rules for desktop 0.3.3 and web 0.4.3, based on e60ae68. Packaged installer validation is recorded separately in docs/VALIDATION-0.3.3.json. All tests use isolated fictional data.

## 实现

- 点修正直接编辑实际上班、实际下班，无时段选择前置步骤。单段只有一对输入，多段/返工全部逐行展开，保留每段和休息间隔。未动字段的秒、毫秒原样保留；只有新补录行可取消，旧记录不会被移除或合并。
- 仍在运行的班次，下班框留空表示继续；填真实下班时间，预览保存后结束误计加班，更新工资、工时、均薪、总结、日历、月报与目标池。跨日仍归原班次日期。
- 过去已记录日期可请假/调休，或同时修正上下班；空白历史可确认排班、工资和真实闭合时段后补录，包括首次使用之前。原始记录起点不移动，不自动补造其他日期，也不向过去扩散固定负担或目标起算范围。
- 未来工作日/休息日直接可辨。计划支持上班/补班、加班、请假、调休及恢复基础排班；只存单日计划，不预记实际工时/收益。补班、请假和调休明确选择不计薪、标准折算或定额补薪；基础休息日不能无中生有保留标准工资。
- 单日调整不改基础周期排班、计薪分母或原固定分摊。已记录日保留快照。未来计划在实际开始时取当日生效工资，兼容今天/明天改薪。
- 休息日选择加班后，基础工资不增长，实际扣午休工作时间参与加班统计；摸鱼再扣有效时间。月均秒薪/时薪=本月净收入÷本月有效时间，平均日薪=本月净收入÷正工时实际工作日数；同日多段只计一天。今日时薪/秒薪仍按今日工资÷今日有效工时，零收入显示 0，零工时显示不可计算。零分母不造无限值。
- 正常工作日延时仍是当天正常工资封顶；不能误设整日无薪加班。下班后返工间隔不计时。实际累计加班严格超过两小时才问是否免费/本次额外加班费，修正关闭运行中班次也遵守；恰好两小时不问。原有加班费保留，本次金额另记，重复保存不重复加钱。
- 历史实际工作日格内显示净利润（含负数、零和休息日实际加班），空白/未来不显示虚构利润。格内金额单位为元、两位小数；长金额换行，点击查看完整详情。隐藏模式隐藏金额、title 和盈亏颜色类别。
- 保存前给影响预览；原时段、加班费、摸鱼保留，日历审计记录每次修改前后快照。历史改假期归档原工时，不算实际工时；是否保留已记加班费有明确选择。撤销需预览，日记录后来变过则拒绝覆盖。目标池按账本重算，可变负，已完成目标结算不回滚、不重复。

## 迁移和回退

没有日历修改时旧格式 1 保持原样。首次保存日历/新时间修正时升级至格式 2，并保留前后日记录与计划审计。新版本可读取 1/2；实际旧版本模型、浏览器备份解析器都拒绝 2，旧桌面存储读到新格式后不能覆盖原文件。

升级前先导出 JSON 备份。回滚旧程序必须恢复升级前备份，不能把格式 2 改成 1 后导回；旧版不理解归档请假，强改会算错收入。仍使用现有桌面保存目录及网页 wonangfei-web-v1 / 1 IndexedDB；没有自动替换数据库。网页通过确认导入/导出保留计划、工资、各段和审计，多标签冲突与配额失败保持事务安全。没有迁移用户真实档案。

## 验证

- 单元：桌面 141、网页 143 项，分别在 UTC、Asia/Shanghai、America/New_York 通过。含大小周、闰年跨月、薪资切换、固定分摊、预期收益边界、成本/目标、加班/返工/午休/摸鱼、历史撤销及格式迁移。
- 日历真实界面：桌面 20 组、网页 19 组通过。包含运行中补下班、重启跨日停止、多行编辑原始毫秒保留、加班费选择与防重复、请假/撤销、未来计划、历史补录、净利润、390 px 长金额及隐藏模式、真实备份导出/网页确认导入。
- 保留功能回归：桌面 15 组、网页 17 组通过。改薪今天/明天、默认补算、返工、目标结算、退休演示槽不混入真实槽、导入/导出、真实 IndexedDB 并发写冲突和配额失败。回归发现导入分支残留旧变量，已修复并重跑通过。
- 网页构建：28 个静态资源；无 preload/Node/桌面桥接，真实 IndexedDB，没有业务联网请求。
- 截图为本机 Electron/Chromium 实际渲染，虚拟数据，测试时钟仅由验收脚本注入，产品不含模拟时钟。


实测 macOS 27.2 Apple Silicon + Electron 45.2.1。Mac 原生 Tray API 另核无薪休息日加班、隐藏标题和无上限进度，未完成物理系统菜单栏鼠标/系统截图验收。Windows、Intel 实机、macOS 15、Safari/Firefox、实体手机未测；390 px 是浏览器视口。Installer validation: docs/VALIDATION-0.3.3.json.

## 本地体验

依赖已存在的工作区可运行 npm start；独立体验用 WORKDAY_DATA_DIR 指向新临时目录，避免改变原档案。源码包不含 node_modules，新机器先按 package-lock.json 使用 npm ci。

- npm test
- npm run smoke（新建隔离虚拟档案，工资/存储回归）
- npm run smoke:calendar（新建隔离虚拟档案，日历与时间修正）
- cd web，然后 npm test、npm run build、npm start，在终端给出的 localhost 地址体验。只读生产静态包需通过本地 HTTP 服务打开，不能直接用 file:// 打开 ES 模块。
