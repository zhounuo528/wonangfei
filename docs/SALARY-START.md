# 工资生效、按排班补算与单个人档案

工资输入统一为「输入到手工资」，不新增税费计算。原有金额保留。

「今天生效」只更新今天工资金额，重算今天收入/净额/平均值/目标池、已有总结和当月报告；保持工时、午休、计薪天数、摸鱼、成本、另记加班费和报告截止时间。「明天生效」保留今天与旧日期，未来新日期取新工资。今天没有记录时只保存规则，不创建工时；稍后开始也按该规则取值。多次修改可替换待生效工资或提前到今天。跨午夜归昨日的班次不因今天改薪而重写。

salaryChanges 和当天 salaryCorrections 保留审计。目标池从账本重算，不重复存入；已完成目标及一次结算保持，降薪可使余池变负，不自动撤销完成或重复扣款。

首次点击开始按当天设定开始补算到现在，扣午休，下班工资封顶；提前点击不计未来工时，过点后显示无薪加班。只补当前日期，不补漏记日。重复点击不多开；返工从实际点击起算，中间休息不计入。上一班开放时阻止新班；结束与今日排班重叠时不重复记时。仍可修正实际开始时间。升级不自动重写旧日期。

生产演示入口、模拟时钟、模式桥接与 demoState 工厂已移除。旧个人档案（包括 demo:null）保留；旧 mode 指向演示也只读个人档案。演示文件/槽原样保留且不解析，不自动合并或删除。只有演示档案时进入空白个人设置；个人档案损坏锁定，不降级读取演示。演示备份不能导入个人账本。若用户曾把实际记录记入旧演示档案，应单独核对，不能自动猜选。

网页仍是 wonangfei-web-v1 / version 1，real 和 mode 修订守卫仍在一笔事务内保存。工资生效规则随 JSON 备份、重启和网页导入保留。桌面原本只提供图形导出，本轮未新增图形导入。

旧版本不理解 salaryChanges：将新备份导回旧版后继续记录，可能提前采用待生效工资。不能仅回退服务资源就认为数据已回退；发布前保留升级前本机备份，优先使用兼容的向前修复。详见 web/DEPLOYMENT.md。
