# 网页版 0.5.0

新增每天／每个工作日重复费用、意外之财、默认关闭的自动上下班，以及下班总结／周月报中的摸鱼估算所得。收入与花销快捷区统一对齐，改善设置文案和变化配色。收入增加为绿，费用增加为红；亏损金额保持红色，改善提示单独表达。

输入框聚焦使用自身边框，下拉采用白色圆角浮层；关闭图标采用产品参考素材旋转 45 度，点击区域至少 44px。宽屏设置页将表单与说明并列，窄屏恢复单列；页面切换回到顶部。

## 数据兼容

记录仍保存在原浏览器的 `wonangfei-web-v1` IndexedDB 中，没有服务器端用户数据迁移。新版本接受格式 1–7；查看页面本身不强制将旧记录升级到格式 5–7。

首次使用每日重复费用、意外之财和自动上下班，分别启用格式 5、6、7。升级前记录保存在 `before-daily-fees`、`before-extra-income`、`before-auto-attendance`；备份和当前记录在同一事务保存。已有有效备份不覆盖，异常备份阻止升级，保留原记录。自动上下班关闭后不降低格式版本。

旧标签页使用原有原子 revision 校验，不能覆盖另一个标签页保存的新档案。测试覆盖备份失败事务回滚、直接 3→7 升级保留三个原始备份，以及旧标签页写入被拒绝。

**0.4.8 只能读取格式 1–4。使用新功能之后，不能靠回退网页到 0.4.8 继续读取新记录。** 出现问题时应保留格式 7 读取能力并修复，或由用户明确选择恢复升级前备份；恢复旧备份会失去备份之后的变更，不能自动恢复或把新数据改标成旧格式。更换浏览器、域名或清空站点数据会改变本地记录的可用性。本次发布保持原域名和数据库名称。

建议升级前导出个人备份，使用新功能后再保留新版备份。发布产物仅包含构建脚本允许的静态资源，不包含任何个人档案、测试档案、凭据或 Electron 文件。

## 实际能力与限制

- 自动上下班从开启当天起补记普通排班，手动记录和修正优先。页面关闭或电脑休眠期间不执行；再次打开／恢复时按时间戳补记。休息日加班仍需手动记录和决定加班费。
- 意外之财归属于所选日期，不制造工时；无有效工时时均薪显示破折号。目标仍从创建日积累，额外收入不摊入摸鱼所得。
- 可定制下拉使用原生 select 的语义、校验和键盘导航，额外处理回车打开；不支持 `appearance:base-select` 的浏览器保留系统下拉。参考：[MDN 可定制 select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)。
- 已在 Mac Electron 和隔离网页 Chromium 验证。网页 320/390px 为模拟视口，未替代手机真机、Safari、VoiceOver 或 Windows 实机测试。本次不生成或发布新版安装包。
