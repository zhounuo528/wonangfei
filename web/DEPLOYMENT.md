## 源码构建

将项目 Root Directory 配为 web，使用已有的 web/vercel.json；buildCommand 为 npm run build、outputDirectory 为 dist，framework 为 null。没有环境变量或外部服务需求。不要把桌面项目根目录的 Electron 依赖用于网页构建。

独立 static ZIP 已构建完毕，根目录直接是 index.html 和其资源；其中 vercel.json 仅配置静态响应头，不需要 npm 构建。该配置与源码构建配置用途不同。包不包含用户数据。

## 数据兼容与回退

数据库仍是 wonangfei-web-v1 / version 1，存储记录格式为 version 1。迁移只更新缺少新模式的全局计薪设置并保存 previousSettings；已记录日期、工资、费用、分摊表与总结快照保持不变。导入旧备份也执行迁移，目标池从账本重算，不另行累计。

上线前请在原域名导出本机档案备份。数据跟随浏览器 origin，不会随 GitHub 或 Vercel部署自动同步；改变域名需要用户主动导入。

回退静态文件不会回退 IndexedDB。旧 0.4.0 校验器可以读取正计薪天数的新字段，但不接受新自动模式中合法的零工作日；这种情况应使用兼容的向前修复，或恢复升级前导出的备份，不得用清空浏览器存储替代回退。
