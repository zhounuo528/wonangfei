# 窝囊费网页版 0.4.2

浏览器本地计薪、成本、摸鱼、净收入目标与工作回顾。无需账号；业务数据保存在当前浏览器的 IndexedDB，网页没有业务联网接口。清理浏览器数据或更换域名不会自动迁移记录，请在设置导出 JSON 备份。

## 本轮更新

工资统一输入到手金额，保存时选择今天或明天生效。今天生效重算今天工资、净额、平均值和目标池；明天保留今天，重启后未来日期仍取新工资。无今天记录时不创建记录，首次点击按该生效规则取值。排班/计薪天数与成本快照不随改薪回写，另记加班费不翻倍。

首次开始从当日设置上班时间补算，扣午休，下班后封顶；提前点击不计未来工时，返工保留休息间隔。没有点击的日期保持空白。演示入口、模拟时钟和切换逻辑已移除，旧演示槽只作原样存档，不读作个人账本；演示备份不能导入。新用户工资初始为空。


- 计薪天数默认按当月考勤工作日计算，覆盖双休、单休、大小周、996、全年无休和自定义工作日。相同设置下完整记录一个月的计划工时，基础工资合计等于月薪。
- 可手动调整本月计薪天数，下月恢复自动。已经记录的日期继续使用各自快照；迟打卡仍按实际记录计时。
- 旧全局设置迁移至自动模式并保存迁移前设置，保留旧日记录、成本分摊表和目标账本。
- 浏览器图标采用透明外缘猫咪；Apple touch 图标保留供系统裁切的底图。

原有上班修正、返工、加班费、摸鱼、目标池、日历/月报、JSON 备份、多标签页并发保护和真实加载页保持可用。浏览器版没有原生菜单栏、置顶或原生系统通知；下班提醒只在页面运行时由应用显示。

## 开发

Node.js 22.12+，没有 npm 依赖：

```sh
npm test
npm run build
npm start
```

打开终端显示的 localhost 地址。生产发布使用 HTTPS。构建仅把 src 中 23 个静态资源复制到 dist，不带个人档案、测试运行数据、桌面桥接或凭据。
