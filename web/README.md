# 窝囊费网页版 0.4.3

浏览器本地计薪、成本、摸鱼、净收入目标与工作回顾。无需账号，业务记录保存在当前浏览器 IndexedDB，没有业务联网接口。

## 本轮更新

- 小日历区分计划工作日与休息日；未来可安排请假、调休、补班或无薪加班，只保存计划，不提前计工时/收益。
- 历史日期可修正上下班、请假/调休，空白历史核对工资与时段后补录。直接编辑时间，无先选第几段；多段返工同时展开，不合并、不丢已有费用。
- 仍在误计加班时，填入实际下班时间并预览保存，即可结束该班次，更新工时、工资、均薪、目标与月报。修改前后留档，安全撤销保护后续改动。
- 历史实际上班日显示净利润，包含负数、零、休息日实际加班；长金额适配窄屏，隐藏模式也隐藏金额标题和盈亏颜色。
- 单日请假和补班不改变基础计薪分母或旧固定分摊。休息日加班基础工资为零，增加实际有效工时和实际工作日，稀释本月净平均秒薪、时薪和日薪；额外加班费另记，不套倍率。

保留今天/明天改薪、默认按设定开始时间补算、五种考勤、摸鱼、目标池、返工、加班费、下班总结、月报、备份导入导出和并发事务保护。工资输入统一为到手金额；演示入口已移除，旧演示槽只归档，不混入个人记录。

## 开发

Node.js 22.12+，没有前端 npm 依赖：

```sh
npm test
npm run build
npm start
```

打开终端给出的 localhost 地址。构建输出 28 个静态资源，不包含用户档案、测试运行数据或 Electron 桥接。浏览器没有原生菜单栏、置顶或系统通知；下班提醒仅在页面运行时显示。

## 数据、迁移与回退

数据库名和数据库版本保持 wonangfei-web-v1 / 1。首次日历或新时间修正把个人记录内容格式从 1 升至 2；新版本读 1/2，旧版拒绝 2，以防忽略请假/调休后错算。发布前在原域名导出旧备份，回退旧应用须配合升级前备份，静态回滚不会回滚 IndexedDB。不要清空站点数据，不要强改格式号，也不要改域名后假定记录自动迁移。新格式审计、目标结算、工资快照和真实工时都随备份保留。

## 验证和交接

143 项单元测试在 UTC、上海、纽约分别通过；19 组日历界面及 17 组工资/存储回归通过。采用本机 Chromium 隔离会话、真实 IndexedDB 和虚拟数据，包含多标签冲突/配额失败、导入导出、隐藏金额及 390 px 视口。Windows、Intel 硬件、macOS 15、Safari/Firefox、实体手机和生产域名未做本轮实测。

源码已准备供提交；生产部署由交接方另行执行。部署、回退及验收见 [DEPLOYMENT.md](DEPLOYMENT.md)，业务口径见 [日历说明](../docs/CALENDAR.md)。本轮不自动部署、不修改 DNS、不更新桌面安装包。
