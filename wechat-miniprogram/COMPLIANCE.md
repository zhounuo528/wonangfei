## 1. ICP 备案

### 前置条件

- [ ] 小程序已完成注册（已有 AppID：`wx03ac8a9499e6a1f1`）
- [ ] 已完成**微信认证**（企业主体 300 元/年；个人主体不能认证，因此个人主体的小程序在类目和支付上受限）
- [ ] 法人 / 负责人能配合**人脸核身**
- [ ] 一个能收短信的手机号（工信部 12381 短信，24 小时内必须核验）

### 需要准备的资料

**企业主体**：营业执照扫描件（彩色、在有效期内、不小于 1500×1100）、法定代表人身份证正反面、小程序负责人身份证正反面、负责人手机号 + 应急手机号（不能与他人重复）、邮箱、精确到门牌号的通讯地址。

**个人主体**：身份证正反面、本人手机号 + 应急手机号、邮箱、通讯地址、人脸核身。

### 本项目怎么填

| 字段 | 填法 |
|---|---|
| 小程序名称 | `窝囊费`（需全局唯一，重名会被驳回） |
| 服务内容类型 | 「工具类 / 效率工具」— 不涉及前置审批项 |
| 是否涉及前置审批 | **否**（新闻、出版、医疗、网约车等都不涉及） |
| 服务器 / 域名 | ⚠️ **本项目无后端、无网络请求、无域名**。被问到时如实说明：纯本地工具，数据保存在用户设备，不上传服务器 |
| 备注 | 可写：「本小程序为个人记账工具，全部计算与数据存储均在用户本机完成，不设服务器，不收集用户信息」 |

> 如果某地管局强制要求填写已备案域名：需要先注册域名并完成网站 ICP 备案（额外 3–7 天 + 域名费用）。按现行流程，无服务器的工具类小程序一般不需要。

### 流程

1. 小程序后台 → 设置 → 基本设置 → 小程序备案 → 填写并上传
2. 平台初审 **1–2 工作日**（可能会接到 0755 开头电话核实，注意接听）
3. 初审通过 → 法定代表人/负责人手机收到 **12381** 短信 → **24 小时内**登录 beian.miit.gov.cn 输验证码核验
4. 通管局审核 **1–20 工作日**（广东通常较快）
5. 下发备案号（形如 `粤ICP备XXXXXXXX号-1X`）

**备案免费**，收费的是微信认证，两者别搞混。

## 2. 服务类目

**建议：`工具 > 效率`**（不需要任何资质）

理由：本小程序做的是「本地记录 + 计算」，没有支付、没有资金流转、没有金融服务。

⚠️ 不要选金融 / 记账 / 财务类目——那类通常要《支付业务许可证》或相关资质，一个纯本地记账工具去选它，等于给自己加一道过不去的门槛。

如果后台类目树里恰好有「工具 > 记账」之类且标注无需资质，也可以选它，更贴合。**选之前先看该类目下的「所需资质」说明**。

## 3. 用户隐私保护指引（最容易被打回）

位置：小程序后台 → 设置 → 基本设置 / 服务内容声明 → 用户隐私保护指引 → 更新 → 增加信息类型。

### 必须声明的一项

| 接口 | 信息类型 | 用途文案（可直接用） |
|---|---|---|
| `wx.setClipboardData`、`wx.getClipboardData` | 读取你的剪切板 | 复制备份内容以便用户自行保存；粘贴用户提供的备份内容以恢复记录。全部在用户主动点击时触发，不上传服务器 |

⚠️ **这是本项目的头号风险**。未声明时表现为：点「导出备份」「导入备份」没反应，控制台报
`setClipboardData:fail api scope is not declared in the privacy agreement`。
开发者工具存在不校验的情况，容易一路带到线上。

### 不需要声明的

位置、相册、摄像头、麦克风、通讯录、微信昵称头像、手机号、设备信息、微信运动——本小程序一个都没用。**不要多勾**，多勾会让审核质疑用途。

### 数据存储说明

可在指引的「其他说明 / 自定义信息类型」里补充一句：

> 本小程序不设服务器，不使用登录，不上传任何数据。记薪、考勤、花销等记录仅保存在用户本机的微信本地存储中，用户可随时在「我的 → 导出备份」自行导出，或「清空本机记录」删除。

### 审核要点

- 用途描述要**对应真实场景**（「复制备份」「粘贴恢复」），不要写「优化体验」这类空话——这是常见驳回原因
- 声明与代码必须一致：声明了剪贴板就得真的用到，用到了别的接口就必须补声明
